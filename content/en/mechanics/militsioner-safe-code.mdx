## Do's and Don'ts for Using and Sharing Codes

Because so much of this knowledge is community-sourced, the quality of what you share matters as much as what you find. A code posted without a build number is a rumor, not a tip.

| Do | Don't |
|---|---|
| Note the game version or build when you post a code | Post a code with no context and call it confirmed |
| Say whether you found it yourself or read it elsewhere | Present wiki content as an official answer |
| Mention which safe and which reward it opened | Assume every safe in the game shares one code |
| Flag it clearly when a code stops working | Leave outdated entries up without an edit |

Safes in this genre are frequently individual. One code opening a flashlight safe tells you nothing about the next locked box you find, so resist the urge to spam 4051 into every keypad you pass. Use it where the community report says it belongs, and solve the rest the way the game intends.
