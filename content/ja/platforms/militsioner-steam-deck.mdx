## 最低要件 vs. Steam Deck ハードウェア

ここからが面白いところであり、正直な期待が重要になるところです。ストアページに公開されている最低要件は異例なほど少ないです。

| スペック | Militsioner 最低要件（記載どおり） | Steam Deck の現実 |
| --- | --- | --- |
| OS | Windows 7 / 8 / 10（64ビット） | SteamOS 3（Linuxベース） |
| ストレージ | 空き容量 20 GB | モデルにより 64 GB〜1 TB |
| CPU / GPU / RAM | ストアページに未掲載 | カスタム AMD APU、共有メモリ |
| コントローラー | Xbox コントローラー対応 | 内蔵ゲームパッドは Xbox レイアウトにマッピング |
| ネイティブ Linux ビルド | 未確認 | Proton 互換レイヤーが必要 |

そこから2つの結論が導かれます。第一に、記載されているのが OS とストレージだけなので、スペック表だけでは性能余裕を判断できません。Valve にもできません。第二に、20 GB というストレージ数値は、ベースモデルの 64 GB Deck を使う人にとって現実的な考慮事項です。OS だけでかなりの容量を消費します。

**実践的なヒント：** まず microSD カードにデモをインストールしましょう。性能が許容できるなら、後で内蔵ストレージに移動すればロード時間を短縮できます。内蔵に大きなインストールを無駄にする必要はありません。

## Militsioner の Steam Deck 性能を自分でテストする方法

Verified バッジを待つ必要はありません。デモと Deck 内蔵のパフォーマンスオーバーレイがあれば、約30分でしっかり判断できます。

1. ストアページから**デモをインストール** — 空きがあれば内蔵ストレージ、なければ microSD。
2. ゲームが起動しない場合は**Proton バージョンを強制**。ゲームのプロパティメニューで互換性を開き、最新の Proton ビルドまたは Proton Experimental を試します。
3. **低または中プリセットで開始。** 1280×800 パネルでは FSR などのアップスケーリングが味方です。
4. **フレームレート上限を設定。** 携帯機では、変動する60よりも30または40 FPS固定のほうが通常は快適です。
5. **パフォーマンスオーバーレイを開く**（レベル3または4）。平均 FPS だけでなくフレームタイムを確認できます。
6. **最も負荷の高いシーンをプレイ** — 混雑した広場、追跡、Colossal Policeman が画面にいるスクリプトシーンなど。

| 記録する項目 | 重要な理由 |
| --- | --- |
| 平均 FPS | ベースラインの滑らかさ |
| 1% low / フレームタイムのスパイク | スタッタリングは低い平均より目立つ |
| 推定バッテリー持続時間 | ステルスゲームは長時間プレイが報われる |
| ファン音と筐体の熱 | 携帯モードの快適さに影響 |
| HUD と字幕の可読性 | Militsioner は14言語のストーリー重視テキストを収録 |
| サスペンド / レジューム動作 | ちょいプレイに重要 |

最も忙しいエリアでデモが安定したフレームレートを維持できるなら、大規模なエンジン変更がない限り、製品版もローンチ時に同様に動作する可能性が高いです。

## 監視ステルスシムは携帯機に合うか？

ジャンルとの相性は互換性の議論では過小評価されがちです。完璧に動作しても、携帯機での体験としては良くないことがあります。Militsioner の設計は概ね好都合な方向に傾いています。

| 設計要素 | 携帯機への影響 |
| --- | --- |
| 一人称ステルスとパルクール | スティック＋ジャイロ照準がよく機能 |
| オープンエンドで探索可能な町 | サスペンド / レジュームと相性が良い |
| 複数の脱出ルートとリプレイ性 | 短い反復プレイを報いる |

| 気分管理とリアルタイム戦術 | ポーズ多用のペースは携帯プレイに合う |

唯一の本当の懸念はテキスト密度です。Militsioner の字幕リストは英語、ロシア語、フランス語、イタリア語、ドイツ語、スペイン語（スペインとラテンアメリカ）、日本語、韓国語、ポルトガル語（ブラジルとポルトガル）、簡体字中国語と繁体字中国語、ウクライナ語をカバーし、英語フルボイス音声付きです。7インチパネルでは会話の多いシーンやメニューテキストが負担になり得ますが、Deck のズーム機能が助けになります。

同種の一人称没入型シムでのプレイヤー経験では、ジャイロ支援照準と40 Hzリフレッシュ上限が、応答性とバッテリー寿命の最良のバランスとなります。

## FAQ

**Militsioner は Steam Deck Verified ですか？**
いいえ。Valve は現在、互換性を Unknown としており、これはレビューが失敗したのではなく保留中であることを意味します。バッジは2027年のリリース前後いつでも変わる可能性があります。

**ゲームを購入する前に Militsioner の Steam Deck 性能をテストできますか？**
はい。無料デモは2026年10月8日から利用可能で、プレイテストの応募も受付中です。Deck のパフォーマンスオーバーレイを使ってデモを実行するのが、自分の体験を判断する最も正確な方法です。

**Militsioner に必要なストレージ容量は？**
記載されている最低要件は空き容量20 GBです。64 GBの Steam Deck をお持ちなら、microSD カードにインストールするか、先に内蔵ストレージの空きを確保することを計画してください。

**携帯機でコントローラーは機能しますか？**
Xbox コントローラーが対応として記載されており、Steam Deck の内蔵ゲームパッドは同じ入力レイアウトを使うため、コントローラーは追加設定なしで割り当てられるはずです。小画面では、入力よりもテキストの可読性が大きな問題です。

**Militsioner の発売日は？**
予定されているリリース時期は2027年です。それまでは、デモとプレイテストが実際に触れて得られる情報の最良の源です。
