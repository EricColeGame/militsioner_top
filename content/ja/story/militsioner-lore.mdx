## ミリツィオネルとは？物語を掘り下げる前の基本情報

多くの脱出ゲームは、警備員でいっぱいの廊下から逃げ切ることを求めます。ミリツィオネルは、街区ひとつ分の大きさの警官一人から逃げ切ることを求めます。そのそびえ立つシルエット — 制服姿の人物が屋根をまたぎ越し、あなたは下の路地に身を潜める — こそが、ミリツィオネルの世界観に関するあらゆる会話の出発点です。これが重要なのは、このゲームでは物語がカットシーンに閉じ込められていないからです。物語は町の建築の中に、常に誰かに見られているという感覚の中に、そして開発者が意図的に招き入れた文学的な亡霊の中に息づいています。

バズったトレーラーだけを見たなら、ミリツィオネルを一発ネタの前提と誤解しがちです。しかしミリツィオネルの世界観を掘り下げると、罪悪感、監視、権威の重みを意図的に研究した作品 — シュールな脱出サンドボックスの装いをまとった — が見えてきます。

| 項目 | わかっていること |
| --- | --- |
| 開発 | TallBoys（ロシアのスタジオ） |
| パブリッシャー | Critical Reflex |
| ジャンル | イマーシブシム、パズル |
| 発売時期 | 2027年 |
| 対応プラットフォーム | Windows、Xbox One、Xbox Series X/S |
| モード | シングルプレイヤー |
| 中心となる前提 | 巨大な警官に見つからずにロシアの町から脱出する |
| 際立った特徴 | マイクを使った会話 |

設定は意図的にシンプルです。あなたはロシアの町に住む普通の住民を操作します。常にあなたの頭上には、巨大な警官がいます。目標は町を出ること — 見つからずに町を抜け出すことです。見つかれば逮捕を意味するからです。名前のついた英雄や悪役のリスト、分岐エンディングの確認、派閥の公式設定集などは発表されていません。ハードなプロットの詳細がこれほど少ないからこそ、ファンの議論はテーマ、象徴性、そして開発者が公に認めた文化的参照にこれほど強く傾くのです。

タイトルそのものが手がかりです。「ミリツィオネル」はロシア語で警察官 — とりわけソビエト時代の民兵警官 — を意味する言葉です。そのためゲームの名前そのものが、物語を怪物狩りではなく国家権力との遭遇として枠づけています。

## 巨大な警官：ミリツィオネルの世界観の中心

ミリツィオネルの世界観におけるすべては、一人の人物を中心に回っています。彼はアニメ的な意味での悪役ではなく、開発者たちはその枠づけに抵抗してきました。2020年9月に最初のトレーラーがTwitterに登場すると、それは急速に広がり、ロシア語圏の報道の多くは敵対的でした — 一部のメディアはロシア恐怖症的だと評し、巨大な警官はソビエトの児童詩に登場する、優しく大柄な警官ステューパおじさんと広く比較されました。

その比較は、ファンが持つ最も有用な解釈の鍵です。ステューパおじさんはソビエト文学における慈悲深い人物です。巨大で、役に立ち、守ってくれます。そのキャラクターを監視国家スリラーに重ねることで、意図的な不協和音が生まれます。巨人は保護者なのか、看守なのか、それとも単に権威という避けがたい事実なのか？ ゲームはその問いを開いたままにしておくよう設計されているようです。

| 解釈 | 何を示唆するか | 裏づけとなる手がかり |
| --- | --- | --- |
| 文字どおりの脅威 | 物理的に逃げなければならない追跡者 | 中心となる脱出目標 |
| 慈悲深い巨人 | ステューパおじさんの系譜；世話役としての権威 | ソビエト児童文学との比較 |
| 人ではなくシステム | 生活の環境条件としての監視 | どこにいても、常に見られている |
| 内面化された罪悪感 | 良心としての監視者 | *罪と罰* からの着想 |

ゲームデザイナーのウラジーミル・セメネツは、その反発に直接言及しました。彼は、警察を悪として描く意図は決してなく、ロシアでの生活についての物語を語り、責任と権力について問いを提起することが目的だと述べました。その発言は、巨人を敵役から議論へと再枠づけします。彼はボス戦というより、足のついた命題文なのです。

## ミリツィオネルの世界観を支える文学的・映画的ルーツ

TallBoysは参照点について異例なほど率直です。確認されているインスピレーションは、フョードル・ドストエフスキーの*罪と罰*、フランツ・カフカの*審判*、そしてアンドレイ・タルコフスキーとニキータ・ミハルコフの映画です。それぞれが物語を特定の方向へ引っ張っており、どれが何をもたらすかを知ると、トレーラーの映像の読み方が大きく変わります。

| 源泉 | おそらくもたらしているもの |
| --- | --- |
| *罪と罰* | 罪悪感、告白、あなた個人を裁いているように思える都市 |
| *審判* | 明示されない罪状での告発；悪夢としての官僚制 |
| タルコフスキーの映画 | ゆっくりと忍耐強いテンポ；記憶、水、朽ちること、精神的な重み |
| ミハルコフの映画 | ロシアの社会的な肌理；道徳的曖昧さ；家族と権威 |

カフカは偏執的なエンジンを供給します。あなたは何かの罪を犯しているのに、誰もそれが何なのか教えてくれません。ドストエフスキーは感情的な代償 — 脱出は赦しとは同じではないという感覚 — を供給します。タルコフスキーは雰囲気とテンポ、つまり荒廃した場所を長く歩くことが追跡シーンよりも多くの意味を持ちうるという考えを供給します。ミハルコフは、シュルレアリスムが完全に浮き去ってしまわないようにする、地に足のついた人間的細部を供給します。

2025年のプレイテストに関するコミュニティの報告は、ゲームがそのよりゆっくりした領域に強く傾いていることを示唆しています。プレイヤーは、巨人の注意が移る瞬間のパニックで区切られた、長い静かな探索の時間を描写しています — 従来のステルスゲームよりもタルコフスキーに近いリズムです。TallBoysは正式な物語の内訳を公表していないため、これは確認されたデザイン方針ではなく、プレイヤー体験として受け止めてください。

## 物語を動かすテーマ：罪悪感、監視、権力

シュールなスケールを取り払えば、ミリツィオネルは監視下で生きることについての作品です。そのテーマは三つの噛み合った形で現れ、それらを理解することが、ミリツィオネルの世界観のより深い層へ入る最短の道です。

| テーマ | どのように現れるか | なぜ重要か |
| --- | --- | --- |
| 監視 | 町の上に常にいる監視者 | 見られることを日常化する；偏執が基準になる |
| 罪悪感 | 罪が説明される前に逃げ出す | 罪悪感は与えられるもので、勝ち取るものではないことを示唆する |
| 責任 | 義務と権力へのセメネツの関心 | 非難を個人からシステムへ移す |
| 脱出 vs. 帰属 | 町は家であり刑務所でもある | 「勝つこと」を道徳的に複雑にする |

ここでの監視は、オフにできるメカニクスではありません — それは天気です。罪悪感は最初からインストールされています。ゲームがあなたのしたことを教える前に、あなたは逮捕から逃げているのです。責任は、デザイナーがはっきりと名指ししたテーマであり、諸刃の剣です。権力が巨大なら、それが行動するとき誰が責任を負うのか？ 警官か、国家か、それとも目をそらす市民か？

最後に、脱出は目標として意図的に満たされないものになっています。町を出ることは、まだその中にいる全員を見捨てることを意味します。その緊張 — 一人の自由 対 多くの安全 — は、カフカとドストエフスキーがともに未解決のまま残すことを好んだ種類の問いであり、だからこそミリツィオネルの物語は発売後も長く議論されるでしょう。

## 脱出ループはいかにしてメカニクスを物語に変えるか

ミリツィオネルはイマーシブシムとして作られており、つまりシステムが物語を運びます。町はルート、気をそらすもの、会話のパズルボックスであり、巨大な警官はあらゆる計画を再形成する絶え間ない圧力です。

| メカニクス | 物語上の機能 |
| --- | --- |
| 視線 | 気づかれること*が*物語である；見えることは脆弱さに等しい |
| マイク会話 | 話すことが演技になる — 嘘をつき、魅了し、時間を稼げる |
| 変装とミスディレクション | 全員が監視されているとき、アイデンティティは流動的になる |
| 開かれた町のレイアウト | 探索と、普通の生活への盗み聞きを促す |
| 失敗状態としての逮捕 | 警察を敵ではなく結末として再枠づけする |

マイク機能はその中でも最も印象的です。実際のマイクに向かって話して会話を進めることは、対話を即興演劇に近いものに変えます。実際には、プレイヤーはただ巨人を避けているだけではありません — 言葉が広まる町で、何を誰に言うかを決めながら、公的な自己を管理しているのです。

オープンプレイテストは2025年8月20日から始まり、およそ2週間延長され、2025年9月18日に終了しました。小規模スタジオにとってそれは長い期間であり、コミュニティに取り組むべき実際の素材を与えました。

プロジェクトの節目についてより広い記録としては、[WikipediaのMilitsioner概要](https://en.wikipedia.org/wiki/Militsioner_(video_game))が、トレーラー論争、公表されたインスピレーション、プレイテストの日付を一か所で追っています。

ゲームの物語を自分で読み解きたいなら、いくつかの実践的な習慣が役立ちます。動く前に巨人の巡回リズムを観察し、あらゆる会話を証拠として扱い、町の人々があなたについてではなく互いについて話すことに注意を払いましょう。世界観は説明ではなく、噂話の中にあります。

## FAQ

**ミリツィオネルには、名前のついたキャラクターたちによる確認済みのプロットがありますか？**
まだありません。開発者は前提 — 巨大な警官が見守る中、ロシアの町から脱出する — を説明していますが、公式の物語内訳、キャラクター名簿、エンディング一覧は公表されていません。そのため、ミリツィオネルの世界観に関する議論のほとんどは、プロット中心ではなくテーマ中心です。

**巨大な警官は悪役ということになっているのですか？**
いいえ、少なくともデザイナーによればそうではありません。ウラジーミル・セメネツは、警察を悪として描くことではなく、ロシアでの生活と責任・権力についての問いを探ることが目的だと述べています。ステューパおじさんとの比較は、この人物をさらに複雑にします。

**このゲームに影響を与えた本や映画は何ですか？**
ドストエフスキーの*罪と罰*、カフカの*審判*、そしてアンドレイ・タルコフスキーとニキータ・ミハルコフの映画が、確認されているインスピレーションです。

**なぜプレイヤーはマイクを使うのですか？**
会話は音声入力で処理でき、それによって社会的相互作用がライブパフォーマンスのように感じられ、見守る町に対して自分がどう見えるかを管理するというテーマが強化されます。

**ミリツィオネルはいつ発売されますか？**
現在の発売時期は2027年で、Windows、Xbox One、Xbox Series X/S向けです。
