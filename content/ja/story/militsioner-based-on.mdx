巨大な警官がロシアの小さな町を見下ろし、あなたの一挙手一投足を監視しています——そして彼の背後にある物語は、ほとんどのプレイヤーが想像するよりも奇妙で、より文学的なものです。Militsionerは、古典ロシア文学、ソ連映画、そして権威に対する日常的な不安を織り交ぜた作品であり、まだ発売前でありながら最も話題を集めるイマーシブシムの一つとなっています。では、Militsionerは正確には何を基にしているのでしょうか。そしてなぜそれが重要なのか。

その答えが重要なのは、ここではインスピレーションが単なる雑学ではないからです。このゲームのあらゆるデザイン上の決断——脱出という目的、そびえ立つ監視者、マイク主導の会話——は、特定の創造的源泉へとさかのぼります。ゲームがどこから来たのかを知れば、トレーラーを正しく読み解き、TallBoysが実際にどのような体験を築いているのかを理解できます。

## Militsionerの概要

影響元を掘り下げる前に、まずは実用的な全体像です。本作はパズル要素を備えたイマーシブシムで、シングルプレイヤー向けに作られており、何年も開発が続いています。

| 項目 | 情報 |
| --- | --- |
| 開発元 | TallBoys（ロシアのスタジオ） |
| パブリッシャー | Critical Reflex |
| ジャンル | イマーシブシム、パズル |
| リリース時期 | 2027年 |
| 対応プラットフォーム | Microsoft Windows、Xbox One、Xbox Series X/S |
| モード | シングルプレイヤーのみ |
| 中心となる設定 | 巨大警官に見張られながらロシアの町から脱出する |

その設定は見かけによらずシンプルです。あなたは地方都市の住民を演じ、巨大な警官が屋根の上にそびえ立ち、あなたの行動を追跡しています。目標は、見つかって逮捕されることなく町を出ることです。この前提は表層であり——より深い層にこそ、インスピレーションが関わってきます。

## 文学的ルーツ：Militsionerが書物のなかで基にしているもの

TallBoysは本作の文学的背骨について率直に語ってきました。繰り返し基準作として挙げられる小説が二つあり、どちらも同じ中心的な問いを扱っています。理性で説得できない権威と個人が衝突したとき、何が起こるのか？

| 書籍 | 著者 | もたらすもの |
| --- | --- | --- |
| *罪と罰* | フョードル・ドストエフスキー | 罪悪感、良心、そして不正行為が心にのしかかる重み |
| *審判* | フランツ・カフカ | 不透明な告発、顔の見えない官僚制、説明のない恐怖 |

Militsionerがこの二冊を基にしているということは、このゲームが警官と強盗のアクションよりも、見られ、裁かれる感覚に関心を置いていることを意味します。ドストエフスキーは道徳的な内面性——登場人物が何かをしてしまった、あるいはそうしたのではないかと恐れ、自らの良心から逃れられない感覚——を提供します。カフカは構造的な悪夢、つまり告発はするが罪状を決して説明しないシステムを提供します。

その組み合わせが、巨大警官が単純な悪役として書かれていない理由を説明します。彼はキャラクターというより、状態に近い存在です——天候や重力のように、その町における人生の事実なのです。あなたは彼を打ち負かすのではありません。彼を避けるのです。

### なぜ巨大警官はボス戦よりも大きいのか

怪物を出し抜いたり、ボスを倒したりすることを期待してプレイすると、その文学的DNAはミスマッチに感じられるでしょう。警官の大きさこそが要点です。監視が物理的な形になり、風景そのものになるまで拡大されているのです。脅威は暴力というよりも、*見られる*ことです。

## 映画的DNA：タルコフスキー、ミハルコフ、そしてじわじわと募る恐怖

インスピレーションの方程式のもう半分は映画です。TallBoysはロシアの監督アンドレイ・タルコフスキーとニキータ・ミハルコフを影響元として挙げており、その選択は、スペクタクルではなく忍耐と圧力を扱うゲームにとって示唆的です。

| 映画監督 | 代表作品 | おそらくもたらしたもの |
| --- | --- | --- |
| アンドレイ・タルコフスキー | *ストーカー*、*惑星ソラリス* | 長回し、朽ちていく環境、精神的・実存的な恐怖 |
| ニキータ・ミハルコフ | *太陽に灼かれて* | ロシア史、道徳的ドラマ、私生活と国家権力のあいだの緊張 |

タルコフスキーの影響は雰囲気に表れます。ゆっくりしたテンポ、風化した建築、そして人の暮らしが感じられ、どこか亡霊じみた世界です。ミハルコフの影響はより人間的です——普通の人々が、自分たちよりもはるかに大きな歴史的・政治的力によって静かに押しつぶされる物語です。

Militsionerの映画的な側面がこの伝統を基にしていることは、このゲームが観察と忍耐に報いることを示唆します。カットシーンを飛ばして目標まで全力疾走するタイプのプレイヤーなら、そのトーンはあなたに抵抗するかもしれません。雰囲気そのものをメカニクスとして楽しむなら、これはまさにあなた向けです。

## ステョーパおじさん、ロシア嫌悪、そして現実に感じられる町

2020年9月に最初のトレーラーがTwitterに登場すると、それは急速に広まりました——そして誰もが同じように受け取ったわけではありません。ロシア語圏のメディアでは、巨大警官はステョーパおじさん——親しみやすく保護的な警察の姿を表す、ソ連の児童書で愛されたそびえ立つキャラクター——と比較されました。批評家たちは、ゲームのイメージはロシア嫌悪的であり、馴染み深い文化的象徴を威圧的な何かに平板化していると主張しました。

| 反応 | 主張 |
| --- | --- |
| バイラルな熱狂 | 海外の観客は、その前提をシュールで、面白く、新鮮だと感じた |
| ロシア語圏からの批判 | 巨大警官は、愛されたソ連的象徴を敵対的に歪めたものとして読まれる |
| 開発者の反応 | 目的は悪意ある警察の戯画ではなく、ロシアでの暮らしについての物語である |

ゲームデザイナーのウラジーミル・セメネツはその批判に直接応答し、警察を悪役として描く意図は決してなかったと述べました。その代わりに彼は、本作をロシアでの暮らしについての物語であり、責任と権力——誰がそれを握り、誰が責任を負い、その下で生きることに何の代償が伴うのか——というテーマについての物語として位置づけました。

Militsionerが純粋なファンタジーではなく、現実の文化的緊張を基にしていることは、それが共鳴する理由の一つです。巨大警官は発明された怪物ではありません。彼は一つの論争であり、その論争は今も続いています。

## 物語がゲームプレイにどう表れるか

インスピレーションは、それがシステムにまで届いて初めて意味を持ちます。ここでは、テーマがプレイヤーが実際に触れられるメカニクスへとどう変換されているかを示します。

| メカニクス | 物語上の目的 |
| --- | --- |
| 巨大警官の視線 | どこからでも見える物理的存在へと変えられた監視 |
| 脱出という目的 | 戦闘ではなく、結果と引き換えに測られる自由 |
| マイクによる会話 | プレイヤーが実際に話す台詞により、社会的交流を即興的で危険なものに感じさせる |
| イマーシブシムのシステム | 単一の脚本された道ではなく、複数のルートと創発的な解決策 |
| パズル構造 | 力ではなく、観察とタイミングで問題を解決する |

マイク機能は最も異例な要素です。会話はマイクで処理でき、それによってゲームは演技寄りになります——単に会話オプションを選ぶだけでなく、緊張感のある社会的やり取りに参加するのです。見られ、裁かれることを扱うゲームにとって、自分の声がそこに混ざることはテーマ的に完璧です。

2025年のプレイテスト期間についてのコミュニティからの報告では、このゲームはゆっくり向き合うのが最良の体験だとされており、それはインスピレーションが示唆するすべてと一致します。これは出口への短距離走ではありません。

## なぜ影響元を知ると話題性が納得できるのか

多くのインディーゲームは、一つの印象的なイメージでバイラルになり、その後消えていきます。本作が注目を維持しているのは、そのイメージが一貫したテーゼと結びついているからです。巨大警官はフックであり、ドストエフスキー、カフカ、タルコフスキー、ミハルコフが、そのフックに重みを与える理由です。

このゲームを追う人にとって、実用的な教訓もあります。トレーラーが公開されたら、インスピレーションのリストと照らし合わせて読むのです。崩れかけた町をゆっくり横切るカメラパンは、埋め草ではありません——それはタルコフスキーの語法です。ぎこちなく、大きな賭けに感じられる会話は、悪い脚本ではありません——それはカフカの語法です。語彙を知っていれば、マーケティングをより解釈しやすくなります。

そして発売時にプレイする予定なら、それに合わせて期待値を設定してください。Militsionerがアクションゲームの慣習ではなく、文学や映画の源泉を基にしているということは、報酬が緊張と雰囲気であり、パワーファンタジーではないことを意味します。スローバーン・スリラーとして向き合えば、デザイン上の選択がかみ合ってくるでしょう。

## よくある質問

**Militsionerは何を基にしていますか？**

Militsionerは、ロシア文学、ソ連時代の映画、そして現代ロシアの暮らしを組み合わせたものを基にしています。開発者は、フョードル・ドストエフスキーの*罪と罰*とフランツ・カフカの*審判*を文学的基準作として挙げ、さらにアンドレイ・タルコフスキーとニキータ・ミハルコフの映画も挙げています。テーマ的には、監視、責任、権力を探求しています。

**Militsionerは誰が開発していて、いつ発売されますか？**

ロシアのスタジオTallBoysが開発し、Critical Reflexがパブリッシュします。予定されているリリース時期は2027年で、Microsoft Windows、Xbox One、Xbox Series X/S向けのバージョンが計画されています。シングルプレイヤー体験です。

**なぜこのゲームはロシア語圏メディアで批判されたのですか？**

2020年9月のトレーラーがバイラルになった後、一部のロシア語報道はそのイメージをロシア嫌悪的と呼び、巨大警官を愛されたソ連の児童向けキャラクター、ステョーパおじさんと比較しました。ゲームデザイナーのウラジーミル・セメネツは、意図は警察の邪悪なイメージを作ることではなく、ロシアでの暮らしと、責任と権力についての物語を語ることだったと述べました。

**このゲームはもうプレイできますか？**

はい、限定的な形でならプレイできます。オープンプレイテストは2025年8月20日から始まり、15日間延長され、2025年9月18日に終了しました。そのため、脱出メカニクスと会話システムが実際にどう感じられるかを知るための、現在利用できる最良の窓口となっています。
