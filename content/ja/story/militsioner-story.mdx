## Militsionerの物語は、あなたが犯していない犯罪から始まる

もし、自分が決してやっていないことで逮捕されたら——しかも、一夜にしてルールが書き換わるように見える町で？ それが**Militsionerの物語**のフックだ。開発はTALLBOYS、パブリッシャーはCRITICAL REFLEXによる、カフカ的なイマーシブ・シムである。これが重要なのは、この物語がただの壁紙ではないからだ。それはすべての脱獄の試み、巨大な警官のあらゆる気まぐれ、そして町が静かに後日のために記録するあらゆる結果を動かす機械なのだ。

あなたは英雄を演じるわけではない。特筆すべき功績もない、ごく普通の何者でもない人物を演じる。だからこそ、その逮捕はあまりにも不条理なのだ。尋問シーンも、証拠も、説明もない——あるのは超現実的な町、パスポート、そして食べかけのバナナだけ。その瞬間から、Militsionerの物語全体は、あなたの想像力と、とても大きく、とても監視の厳しい障害物との間の交渉になる。

前提を最も単純な形で示すと：

| 物語の要素 | あなたにとっての意味 |
| --- | --- |
| あなたの役割 | 目立った過去のない、平凡な市民 |
| 発端となる出来事 | 犯した記憶もない犯罪による突然の逮捕 |
| 開始時の所持品 | パスポートと食べかけのバナナ |
| 舞台 | 立ち去ることを許されない超現実的な町 |
| 中心となる障害 | あなたの一挙手一投足を追う巨大な警官 |
| コアループ | 脱獄を計画し、成功するか捕まるかして、より賢く再挑戦する |

欠けているものに注目してほしい。ミッションブリーフィングも、「正しい」脱出方法を説明する目的マーカーもない。ゲームが渡してくるのは解決策ではなく、問題だ。それこそが要点なのだ。

## 巨大な警官はMilitsionerの物語の鼓動する心臓だ

町、列車、花を取り除いても、Militsionerの物語は一つの関係の上に成り立っている。あなたと彼（HIM）だ。巨大な警官は、あなたを町の境界の内側にとどめておくために存在する。彼は巨大で、いつも近くにいて、そして物事に気づく——あなたが気づいてほしくないことまで。

しかし、ここから物語は面白くなる。彼は台本通りの壁ではない。彼には気分があり、その気分はゲームプレイのシステムだ。公式資料は、彼を怒らせ、おだて、失望させ、欺き、さらには恋愛対象にすることさえ公然と促している。彼は最近気難しいと評されている。巨大な警官についてそう言うのは奇妙だが、知っておくと非常に役立つことでもある。

| 感情のレバー | どう作用するか |
| --- | --- |
| 怒り | 彼を挑発すると、より手強く、より注意深い障害になる |
| お世辞 | 彼の態度を和らげ、息つく余地を稼ぐ |
| 失望 | 彼を失望させると、あなたを監視する度合いが変わるかもしれない |
| 欺瞞 | あなたの意図や行動について彼を誤導する |
| 恋愛 | 贈り物で彼に求愛する——花が効果的——そして可能なら彼をデートに誘う |

最後の行は、プレスリリースに紛れ込んだ冗談ではない。力ずくも窃盗も失敗したとき、誘惑は本気の代替手段として提示されている。怪獣サイズの警官を色目で通り抜けさせてくれるゲームは、自分がどんな物語を語りたいのかについて声明を出している。つまり、「正しい」解決策とは、あなたが正当化できるものすべてだという物語だ。

## 町は覚えている：Militsionerの物語における結果

多くのステルスゲームは、失敗すると世界をリセットする。Militsionerの物語はリセットしない。証拠をしっかり取っておくのだ。

公式資料で最も明確な例は列車に関するものだ。あなたは運転士と共謀して列車に忍び込む。計画は崩壊する。列車は大破し、運転士は負傷する——そしてその負傷はあなたの責任だ。次は別のルートを取り、その従業員と企むのではなく駅で仕事に就けば、運転士は無事に済む。同じ町、同じ目的、まったく異なる巻き添え被害だ。

その設計哲学は、Militsionerの物語にどう向き合うべきかを形作る：

- **あらゆる行動が記録されると考えよ。** 町は、あなたが捕まったかどうかだけでなく、何をし、何を言ったかを追跡している。
- **NPCを長期的投資として扱え。** 1回目のプレイで搾取した人物が、2回目では戦力になるかもしれないし、障害物になるかもしれない。
- **手順ではなく連鎖で考えよ。** どこかに侵入することが、取引の資金になり、その取引が列車を完全に避けるルートを解放するかもしれない。
- **「被害者のいない」犯罪を考え直せ。** たいてい被害者はいる。ただ、それがあなたではないだけだ。

| あなたのやり方 | 町への波及効果 |
| --- | --- |
| 列車の運転士と共謀する | 列車は破壊され、運転士は負傷し、ルートは閉ざされる |
| 駅で仕事に就く | 運転士は健康なままで、ルートは利用可能なまま |
| 品物を盗んで売る | 所持金と所持品が変わり、疑いが強まる |
| 正直に取引する | 進行は遅いが、敵は少ない |
| 警官を誘惑する | 関係が変わり、監視の度合いが下がるかもしれない |

開発者が投げかける最後の問いは示唆的だ。あなたは自分が無実だと信じて始めた——外に出るころには、まだ無実だろうか？ それがMilitsionerの物語の感情的な背骨だ。脱獄が目的だが、その代償は道中でどんな人間になったかによって測られる。

## 脱獄ルート：Militsionerの物語はどう分岐するか

Militsionerは非線形のイマーシブ・シムとして作られているため、自由は一つの扉ではない。町を探索し、マップを偵察し、環境が与えてくれるものから出口を組み立てる。盗み、売買、取引、侵入、忍び出る——そのすべてが選択肢だ。

| 脱獄のアプローチ | 求められるもの | リスクの性質 |
| --- | --- | --- |
| ステルスと忍び足 | 忍耐、ルートの知識、目立たないこと | 低い騒音、高い緊張 |
| 窃盗 | タイミング、度胸、品物を売る仲買人 | 疑いが急速に強まる |
| 取引と販売 | 花などの見つけた資源 | 遅いが安全 |
| 侵入 | 道具、機会、脱出計画 | 高報酬、高警戒 |
| 雇用 | アクセスのために正当な仕事に就く | 静かだが時間がかかる |
| 誘惑 | 贈り物、お世辞、彼（HIM）との繰り返しの接触 | 予測不能だが柔軟 |
| 直接対決 | 力ずく | たいてい最悪の選択肢 |

有用な考え方がある。各ルートはそれぞれ異なるジャンルだ。ステルスはパズルゲーム、窃盗は強盗もの、取引は経済シミュレーション、そして恋愛ルートは——本当に——巨大な警官との人間ドラマだ。Militsionerの物語は、自分がどれをプレイするかを選ばせてくれる。

これらのシステムについて公式の完全な内訳を知りたいなら、[SteamのMilitsionerページ](https://store.steampowered.com/app/1373530/Militsioner/)でデモ告知とともにメカニクスが説明されている。

## 脱獄の試みはすべてMilitsionerの物語を書き換える

捕まることはゲームオーバー画面ではない。それは物語の一節だ。

巨大な警官があなたを止めたとき、あなたはゼロからやり直すのではない——*情報を得た状態*からやり直す。彼は前回あなたがしたことを覚えており、それに応じて行動を調整する。つまり、二度目の試みはリトライではなく、より賢い敵役を迎えた続編なのだ。

| | 最初の試み | 二度目の試み |
| --- | --- | --- |
| あなたの知識 | ルートを推測している | どの道が監視されているか知っている |
| 警官の行動 | 基本の巡回ロジック | 前回のやり方に適応している |
| 町の状態 | まっさらな状態 | 1回目の結果を引き継いでいる |
| 最善の戦略 | 幅広く実験する | 特定の盲点を突く |

だからこそ、リプレイ性がゲームのタグの中でも目立って位置づけられている。Militsionerの物語は何度も語られるように設計されており、あなたが先に変わったから、語られるたびに変化する。

はっきり言っておくべき注意点が一つある。MilitsionerはまだSteamにユーザーレビューがないため、知られていることの大半は公式発表とデモ資料から来ている。初期プレイテストからのコミュニティ報告はまだ薄い——ストアページ以外の情報は、確認された事実ではなくプレイヤー体験として扱ってほしい。

## よくある質問

**Militsionerの物語は実際何についてのもの？**
あなたは、犯していない犯罪のために超現実的な町で逮捕された普通の人物だ。巨大な警官があなたの退去を妨げ、あなたの仕事は脱出方法を見つけること——ステルス、窃盗、取引、欺瞞、あるいは恋愛によって。Militsionerの物語は、逃げるために自分の無実をどこまで曲げるかについての物語なのだ。

**本当に巨大な警官と恋愛できる？**
はい、公式資料によれば可能だ。花は彼に色目を使うための保険の贈り物として取っておけるし、ゲームは彼（HIM）をデートに誘う可能性について明言している。力と窃盗が失敗したときの代替手段として位置づけられている。

**Militsionerはもう発売されている？**
いいえ。発売予定日は2027年だが、2026年10月8日に無料デモが利用可能になり、プレイテストはアクセス申請を受け付けている。Steamでウィッシュリストに追加すれば、発売時に通知を受け取れる。

**選択は脱獄の試みの間で引き継がれる？**
はい。町はあなたがしたことや言ったことを覚えており、巨大な警官は前回のやり方を思い出して行動を調整する。だからMilitsionerの物語は、同じ方法を二度力ずくで通すのではなく、新しいアプローチで繰り返しプレイされるべきなのだ。
