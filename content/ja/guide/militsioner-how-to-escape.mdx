## 巨大警官を読む：機嫌こそが本当の地図

ほとんどのステルスゲームは、パトロールを避けることを求めてくる。Militsionerは、関係を管理することを求めてくる。巨大警官は、あなたが怒らせ、おだて、失望させ、欺き、さらには恋愛対象にできる相手として描かれている。その感情の幅こそが、実際の脱出システムなのだ。

| アプローチ | プレイ中の見え方 | 役立つ傾向があるとき |
|---|---|---|
| お世辞 | 褒める、贈り物、話に乗る | 彼があなたに中立か好奇心を持っている |
| 欺瞞 | 偽の痕跡、ミスディレクション、静かな嘘 | 移動や物色の時間が必要なとき |
| 怒り | 反抗、対立、拒否 | まれ——警備が厳しくなるリスクが高い |
| 失望 | 信頼を裏切る、約束を破る | 意図しないもの。彼が態度を固める前に素早く修復する |
| ロマンス | 花、贈り物、デートに行く | 大きな見返りを狙う長期戦 |

デモに関するコミュニティ報告では、彼の状態は試行をまたいで引き継がれる可能性が示唆されている。つまり、前回彼にどう接したかが、今どれだけあなたを注視するかを形作る。嘘で彼の信頼を損なったなら、余裕は少ないと考えるべきだ。魅了したなら、少しの息抜きが期待できる——そしてそれをすぐに使おう。

### ジョークではなくメカニクスとしての口説き

公式説明はこの点について率直だ。見つけた花は売る、交換する、あるいは巨大警官を口説くための切り札として取っておくことができる——うまくいけばデートにつながるかもしれない。それはフレーバーテキストではない。彼を走って振り切れず、戦っても勝てないプレイヤーにとっての別の進行ルートなのだ。

## Militsionerの脱出方法：通用する7つの原則

これらの原則はデモの設計ロジックから来ており、どのルートを選んでも通用する。

| 原則 | 重要な理由 |
|---|---|
| 静かに、低く動く | 検知を左右するのは距離よりも騒音と視認性 |
| 動く前に偵察する | ルートを知っていることは、その上を速く進むことより価値がある |
| 小さな経済を築く | 花や交易品が賄賂、道具、好意の資金になる |
| 合法的なカバーを使う | 本物の仕事は隠れるより優れた変装になり得る |
| 失敗した計画を決して繰り返さない | 彼は前回の試みを覚えていて、それに適応する |
| 位置だけでなく機嫌を見る | 感情状態が彼の許容範囲を変える |
| 失敗を想定して計画する | すべての脱出は異なるものになるよう設計されている |

5番目の原則は、プレイヤーが最も過小評価するものだ。同じ操車場のトリックを2回試すなら、あなたは自分の腕を試しているのではない——彼に対抗されるパターンを渡しているのだ。

## リスクとリターンでランク付けした脱出ルート

Militsionerに単一の出口はない。町は開かれており、開発者は盗み、売買、交換、侵入、こっそり抜け出すことを有効な選択肢として明記している。それらのアプローチを比較すると以下のようになる。

| ルート | 難易度 | リスク | 備考 |
|---|---|---|---|
| 静かに抜け出す | 中 | 中 | 基本。警戒が高まる前の序盤に最も機能する |
| 交易と賄賂 | 低〜中 | 低 | 遅いが安定。収入源が必要 |
| 盗みと侵入 | 中〜高 | 高 | 進行は速いが、盗みはついて回る傾向 |
| 合法的な仕事に就く | 低 | 低 | 優れたカバー。自由への最も遅いルート |
| 列車脱出 | 高 | 非常に高い | 計画が崩れると悪い結果になると記録されている |
| 町をパルクールで移動 | 中 | 中〜高 | 偵察と位置調整に最適 |
| 警官とロマンス | 高 | 高 | 独特の見返りがある長期戦 |

賢いランでは通常、2〜3つを組み合わせる。パルクールと静かな偵察で町を学び、正直な交易で金を作り、本当に賭けるつもりの試みのために高リスクの選択肢を1つ温存しよう。

## そのまま使える段階的な脱出の試み

以下の手順はスクリプト化された解答ではなく、一般的な枠組みだ。細部はプレイ中のデモ版で提供されるものに合わせて調整してほしい。

| ステップ | 行動 | なぜやるのか |
|---|---|---|
| 1 | 何も盗まずに町を歩く | 警戒ゼロでレイアウトと彼の巡回リズムを学ぶ |
| 2 | 花や小さな交易品を拾う | 賄賂と道具のための初期資金を作る |
| 3 | 仕事や合法的なタスクを引き受ける | カバーストーリーと収入。目立つが無害でいられる |
| 4 | 小さな欺瞞を1つ試す | 彼がどれだけ気づき、どれだけ速く反応するか確認する |
| 5 | 脱出ルートを1つではなく2つ特定する | 冗長性こそサンドボックスの要点 |
| 6 | 本当に必要な道具や好意に金を使う | 経済を能力に変換する |
| 7 | 注意が低い瞬間に動く | タイミングは速度に勝る |
| 8 | 捕まったら、計画を完全に変える | 彼は覚えているので、繰り返しは失敗する |

ステップ1から4は本質的に偵察だ。これを飛ばすプレイヤーはたいてい、準備不足の試みに最高のアイデアを燃やしてしまう——そして、脱出が失敗した後でも町がその試みを覚えていることに気づく。

## 結果：町は記録を残す

公式資料で最も明確な例の1つは列車に関するものだ。列車運転手と共謀し、計画が瓦解すると、列車は破壊され、運転手は負傷する。別のアプローチで再挑戦する——たとえば代わりに駅で働く——と、運転手は無事に済む。

これは設計上の約束を縮図にしたものだ：

- あなたの行動は単なる失敗カウンターではなく、ワールドステートとして持続する。
- 警官以外のキャラクターもあなたの計画によって傷つけられ得る。
- 彼らを守る、より穏やかで遅い道がしばしば存在する。
- 巨大警官はあなたがしたことを覚えており、行動を適応させる。

| 前回したこと | 世界が覚えていること | 今どう対応するか |
|---|---|---|
| 開けた通りを大声で走った | 高い視認性、厳しい監視 | 屋内と垂直ルートに切り替える |
| 警官に嘘をついた | 信頼低下、余裕減少 | 行動前に贈り物や正直さで修復する |
| 計画中にNPCを傷つけた | 傷ついた関係とワールドステート | 代わりに遅く合法的なルートを取る |
| 彼をうまく魅了した | 少しの息抜き | その窓をすぐ使う。無駄にしない |

## プレイヤーが捕まるよくある間違い

| 間違い | なぜ悪いか | より良い行動 |
|---|---|---|
| スプリントのように扱う | 速度は時間を節約する以上に注意を引く | ゆっくり意図的に動く |
| 機嫌システムを無視する | 1つの関係ではなく町全体と戦うことになる | お世辞、贈り物、ロマンスに投資する |
| 花や品物を溜め込む | 交換されない資源は無駄なレバレッジ | アイテムを道具や好意に変換する |
| 失敗した計画を繰り返す | 彼はすでにそれに適応している | 方法、ルート、タイミングを完全に変える |
| 短期的利益のためにNPCを犠牲にする | 町は負傷と裏切りを覚えている | 人を無傷で残す計画を好む |
| 脱出ルートを1つしか持たない | 1つの対抗策でランが終わる | 常にバックアップを偵察する |

このガイドから1つだけ持ち帰るなら、最後の行を持ち帰ってほしい。Militsionerのすべてのメカニクス——機嫌トラッキング、持続する町、適応する警官——は、予測可能性を罰するように設計されている。**Militsionerの脱出方法**を理解することは、あなたの二番目に良いアイデアこそがしばしばうまくいくと理解することだ。まさに彼が最初のアイデアを警戒していたからである。

## よくある質問

**Militsionerはもう出ていますか？今から脱出を練習できますか？**
完全版はまだです。リリース予定は2027年ですが、2026年10月8日から無料デモが利用可能で、Steamではプレイテストの登録も受け付けている。フルゲーム到着前に**Militsionerの脱出方法**を試す最良の場所はデモだ。

**巨大警官を振り切る代わりに、本当にロマンスできますか？**
はい——公式説明では彼を口説き、うまくいけばデートに誘うこと、見つけた花を贈り物や交渉材料として使うことが明記されている。ステルスや盗みに対する本物の代替手段のようだが、おそらくより遅い。

**捕まるとすべてリセットされますか？**
いいえ。設計は各脱出が異なること、警官が前回の試みを覚えて適応することを強調している。きれいな状態ではなく、持続する結果を想定しよう。

**最も信頼できる脱出戦略は何ですか？**
忍耐と柔軟性。徹底的に偵察し、交易で小さな経済を築き、少なくとも2つのルートを開いておき、失敗するたびにアプローチを変える。適応を中心に作られたゲームでは、固定のトリックは繰り返し使っても生き残らない。
