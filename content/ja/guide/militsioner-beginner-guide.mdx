## Militsionerとは？ プレイ前の入門

Militsionerは、小さく抑圧的な町を舞台にした一人称の「逃亡シミュレーター」だ。あなたは明言されない罪で逮捕されており、看守は普通の警官ではない——通りや屋根、窓を越えて手が届く、そびえ立つ巨大警官なのだ。その雰囲気は意図的にカフカ的で、官僚的、超現実的、そして静かに威圧的である。

ほとんどのステルスゲームとこれを分けるのは会話だ。音声入力を使って巨大警官や他のキャラクターに話しかけられるため、悪い状況を話術で切り抜けることは、忍び込んでやり過ごすことと同じくらい重要になる。シューターや純粋な隠れ鬼ごっこを期待して始めると、ほぼすべての遭遇を読み違えるだろう。コミュニティの報告は一貫して、この体験を緊張感があり、奇妙で、反射神経よりも即興によって進むものだと述べている。

| 要素 | 期待できること |
| --- | --- |
| ジャンル | 一人称の超現実的な逃亡シミュレーター |
| 視点 | 一人称、近距離で閉塞感がある |
| 中心となる緊張 | 巨大警官に監視されること |
| 看板メカニクス | 巨大警官や町の人々との音声会話 |
| 雰囲気 | カフカ的、ダークコメディ、不穏 |
| 戦闘 | 中心ではない——回避と会話が重要 |

## Militsioner 初心者ガイド：脱出を左右する中核システム

新規プレイヤーは、Militsionerを従来型のステルスゲームのように扱うために失敗しがちだ。そうではない。4つのシステムがほとんどの役割を担っており、早い段階で理解すれば何時間もの苛立ちを節約できる。

**視線。** 巨大警官の視線が中心的な脅威だ。物陰に隠れているだけでは十分ではない——高低差、開けた地面、遠くからどれだけ見えるかも考える必要がある。建物の間を移動し、壁や車両を使い、長くまっすぐな通りを避けよう。

**注意と疑念。** 見つかることが即失敗になることはほとんどない。重要なのは、どれだけ注意を蓄積するか、そして警官に近づく理由を与えるかどうかだ。大きな音を立てる行動、繰り返すミス、開けた場所での長居は、いずれも事態を悪い方向へ押しやる。

**声と会話。** 発話は飾りではなく道具だ。キャラクターと話すことで緊張を和らげ、情報を集め、時間を稼げる——ただし不注意な発言は疑いを強めることもある。

**時間と機会。** 好機の窓は開いたり閉じたりする。隙間を見た瞬間に無理やり逃げるよりも、適切な瞬間を待つほうが賢いことが多い。

| システム | 役割 | 初心者の優先度 |
| --- | --- | --- |
| 視線 | 監視されているかどうかを決める | 最優先 |
| 注意レベル | どれだけ警戒を招いたかを追跡する | 高 |
| 音声会話 | 情報と注意そらしの選択肢を開く | 高 |
| タイミング | いつ脱出が現実的になるかを左右する | 中 |
| インベントリ／道具 | 特定のルートと計画を支える | 中 |

### 状況を悪化させずに声を使う方法

音声インタラクションはMilitsionerの最も特徴的な要素であり、初心者にとって最も裏目に出やすい要素でもある。はっきり話し、返答は短くしよう。周囲が騒がしい場合や相部屋の場合は、脱出の途中で発話に頼る前に、設定で入力オプションを確認しておこう。

| すべきこと | 避けること |
| --- | --- |
| 短くはっきりした文で話す | だらだら話す、同じことを繰り返す |
| 話しかけているキャラクターの口調に合わせる | 序盤に巨大警官を脅す |
| 会話を使って時間を稼ぎ、観察する | 開けた場所を忍び歩きながら話す |
| 緊張する場面の前にマイクをテストする | すべてのNPCが同じ反応をすると決めつける |

## 最初の1時間：ステップバイステップ計画

最初の1時間は、英雄的行動ではなく情報収集に充てるべきだ。コミュニティの報告によれば、最も早く脱出するプレイヤーは、最初のプレイで最寄りの出口へ全力疾走するのではなく、町の地図を作ることに時間を使う人たちだ。

| ステップ | 行動 | 重要な理由 |
| --- | --- | --- |
| 1 | 開始エリアの外周を歩く | 出口、遮蔽物、巡回の視線を明らかにする |
| 2 | リスクの低いキャラクターで音声システムを試す | 高圧的な会話の前に自信をつける |
| 3 | 巨大警官が見える場所と見えない場所を把握する | 安全に移動できる経路を定義する |
| 4 | 短期的な目標を1つ決める | やりすぎずにプレイに方向性を与える |
| 5 | 小さく低リスクな行動を試す | ゲームがミスをどう罰するかを学べる |
| 6 | 注意が急上昇したら退いて立て直す | 早すぎる、避けられた捕獲を防ぐ |

一度その頭の中の地図ができれば、2回目のプレイはずっと楽に感じられる。どの路地が行き止まりか、どの会話に価値があるか、そして警官の注意が問題になる前に、開けた場所にどれくらい留まれるかがおおよそ分かるだろう。

## 初心者が避けるべきミス

序盤の失敗のほとんどは、少数の癖から生まれる。これらを直せば、脱出成功率はすぐに上がる。

| ミス | なぜ有害か | 解決策 |
| --- | --- | --- |
| どこでも全力疾走する | 音と動きが視線を引く | 歩く。全力疾走は視線を切るときだけ |
| 会話を無視する | 情報と安全な選択肢を逃す | 行動する前にキャラクターと話す |
| 1つの脱出ルートに固執する | 注意が高まるとルートは閉ざされる | 常に予備計画を持つ |
| 使わないアイテムを溜め込む | 時間とインベントリ容量を無駄にする | ルートに必要なものだけ持つ |
| 見つかったときに慌てる | さらに悪い位置へ走り込む原因になる | 視線を切り、止まって立て直す |
| 地図作りを完全に省く | 追い詰められるのが確実になる | 決行する前に探索する |

役立つ目安として、急かされていると感じるなら、おそらく実際に急かされている。Militsionerは速さよりもはるかに忍耐を報いる。ゆっくり慎重なアプローチは、速く騒がしいアプローチにたいてい勝る。

## 脱出計画と優先事項

成功する脱出は、幸運な突破ではなくチェックリストだ。どの計画を実行する前にしても、以下の基本を押さえているか確認しよう。

| 優先度 | 準備 | メモ |
| --- | --- | --- |
| 1 | 実行可能なルートを2つ知る | 主ルート1つ、退避ルート1つ |
| 2 | 現在の注意レベルを把握する | 注意が低いほど自由が増す |
| 3 | 注意そらしを用意する | 会話と物音のどちらも有効 |
| 4 | インベントリを確認する | ルートに必要なものだけ持っていく |
| 5 | 最初の60秒を計画する | 失敗の多くは序盤に起きる |
| 6 | 撤退ポイントを決める | いつ試みを諦めるべきか知る |

コミュニティが書いた戦略やルート解説については、基本を自分で理解した後の次の一手として[Steamのプレイヤー制作ガイド](https://steamcommunity.com/app/1373530/guides/)が良い。また、[IGNのMilitsionerハブ](https://www.ign.com/games/militsioner)のような大手メディアは、このゲームが何であり、音声主導のデザインがどう機能するかを確認するのに役立つ。

最後に、失敗はこのループの一部だと覚えておこう。捕まるたびに、視線、タイミング、会話について何か具体的なことを学べる——その知識は次の試みに直接活きる。

## よくある質問

**Militsionerをプレイするにはマイクが必要ですか？**
音声入力はこのゲームの看板機能なので、動作するマイクがあれば最も充実した体験ができる。使えない場合は、会話の途中で困らないよう、プレイを始める前に設定で入力方法を確認しておこう。

**巨大警官の視線を避けるにはどうすればいいですか？**
頑丈な遮蔽物の後ろに留まり、長く開けた通りを避け、長い全力疾走ではなく短い移動を繰り返そう。高低差と距離は、壁と同じくらい重要だ。

**見つかったときは話すべきですか、逃げるべきですか？**
まず視線を切ろう。隠れたら、特にプレイ序盤では、落ち着いた会話のほうがもう一度全力疾走するより時間を稼げることが多い。

**Militsioner 初心者ガイドで教えられないことはありますか？**
ルートや会話の結果は、注意レベルと選択によって変わるため、Militsioner 初心者ガイドでできることには限りがある。残りは、試して、うまくいったことを記録し、プレイごとに自分の脱出計画を磨くことから得られる。
